# docs/visuals — curated visual record

Location is the decision: `shots/` is gitignored scratch for the
screenshot critique loop (dozens of throwaway captures per session);
anything worth keeping gets promoted **here** and committed.

Keep it curated — one or two captures per site per identity milestone
(shipped hero, signature interaction, mobile), named for what they show,
not when they were taken. These double as the reference imagery the
taste profiles point LLMs at (see `docs/nocturne-taste-profile.md`), so
they must always reflect the shipped state.
