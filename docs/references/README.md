# Concept references

Curated pre-build visual anchors live here. They are distinct from
`docs/visuals/`, which records shipped-site milestones, and from each site’s
eventual `assets-src/`, which holds production image sources.

- `aubade-hotel-one/` — canonical residential-hotel interiors
- `aubade-hotel-two/` — canonical contemporary-hotel color board

Hotel One’s custom-GPT instructions, reference protocol, shot prompts, and
review gate live in
[`../aubade-hotel-one-photography-gpt.md`](../aubade-hotel-one-photography-gpt.md).

These JPEGs are lightweight working references derived from the owner’s source
files. When a project is named and scaffolded, copy its selected original
sources into that site’s private source-asset pipeline and generate fresh
public derivatives there. Do not make a production page depend on `docs/`.
