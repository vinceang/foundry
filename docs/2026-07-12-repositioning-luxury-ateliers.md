# Repositioning: from "range of categories" to "heritage-craft ateliers"

**Date:** 2026-07-12
**Decision maker:** Vince

## What changed

The original brief asked for three unrelated site categories — ecommerce, SaaS, event — deliberately mismatched to prove generic range ("if any two look related, one of them is wrong"). Two sites in (Suntoku/寸徳, formerly "Kaji", and Shokunin — both Japanese heritage-craft ateliers, built in parallel sessions), Vince realized the thing he actually wanted to keep making wasn't range-for-its-own-sake — it was *this specific register*: hushed, reverent, materially honest luxury, built around real personal passions rather than invented briefs.

The repo's thesis pivoted accordingly: **a collection of bespoke heritage-craft atelier sites, one per culture/craft Vince genuinely loves**, unified by register (quiet luxury, restraint, real domain authenticity) rather than by category diversity. Distinctiveness now comes from *which* craft and culture, not from deliberately clashing categories.

## What was retired

Two concepts, planned but never built, were retired because they contradicted the new thesis — one by tone, one by category:

- **Roster** (`sites/saas`, now repurposed as `sites/vicente`) — a SaaS product where users "hire AI agents like virtual teammates" for personal tasks, content, and support, taught in plain English with visible permissions/approvals. Planned identity: *warm*, human, calm-premium — cream/ink/terracotta, humanist type, an interactive "meet your teammates" hero, generated agent portraits, an animated permissions flow. This was Vince's own concept and a strong SaaS pitch on its own terms — it just doesn't belong in a hushed-luxury collection. Worth revisiting as a standalone project if the SaaS-range idea returns.
- **SIGNAL** (`sites/event`, now repurposed as `sites/schwarzwald`) — an experimental music + light-art festival. Planned identity: loud, maximal, immersive, high-contrast duotone, oversized expressive type, heavy generative motion — a deliberate opposite-energy counterweight to the other sites. Never designed past the one-line concept. The "loud maximal" register has no obvious luxury-atelier equivalent; if revisited, it would need to be a different project entirely, not a reskin.

Neither needs to be resurrected — they're documented here so the reasoning and any reusable ideas (the agent-portrait generation approach, the permissions-flow animation, the generative-motion techniques) aren't lost.

## What replaced them

Two new concepts, chosen because Vince has genuine, specific enthusiasm for each — the same quality that made Suntoku's authenticity work:

- **Vicente** (working subtitle: *Lutier*) — a family-owned boutique guitar-making atelier, the Vicente family, Andalusia (Córdoba), Spain. Ecommerce. Rich chiaroscuro asset potential: tonewoods, rosettes, binding, the luthier's hands. Planned language switching (EN/ES) as both a technical showcase and true to the story of a regional family business serving the world. Lives in `sites/vicente`.
- **Cuckoo clock house** (name not yet chosen) — a Black Forest / Bavarian clockmaking family house, Germany. Ecommerce. Same chiaroscuro potential: hand-carved cases, movements, gears, the workshop. Planned language switching (EN/DE). Lives in `sites/schwarzwald` (placeholder folder name — German for "Black Forest" — pending a real brand name, the same way `sites/kaji` stayed as the folder name after the Suntoku rebrand).

Both should follow the same discipline that made Suntoku and Shokunin work: real domain terms (not invented or pastiche), each with its own `DESIGN.md` once built, its own asset-generation recipe, and its own three-plus critique passes per the original build discipline — none of that changed, only the thesis choosing *what* gets built.

## Naming note

"Córdoba" is also the name of an existing real guitar-making company (Córdoba Guitars). Not a blocker for a portfolio showcase, but worth knowing if this ever moves beyond a demo.
