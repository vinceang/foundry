# Foundry fingerprints

The registry of shapes already taken. Read it **before** building, check the
planned build against it **before writing markup**, and append one row **after
shipping**.

The gate exists because the collection kept varying *world* and holding *shape*
constant. Twenty-five sites, twenty-five places, twenty-five crafts — and one
page. Every complaint that has ever been raised about this collection is a
symptom of that: 23 of 25 sites set in a serif, one human figure per site, an
inherited dark, and one hairline meter component wearing two palettes on
Malmfuru and BENT.

> The world changes how a site **looks**. The grammar changes what a site **is**.
> A build that only changes world is a re-skin.

Adapted from the fingerprint gate in Nate Herk's `scrollcraft`
(<https://github.com/nateherkai/scroll-craft>, MIT). The six dimensions below are
Foundry's own; the gate mechanic is his.

---

## The six dimensions

Both phases share this table. Foundry and Sluice use the same tools, the same
taste and the same showcase, so they are fully capable of colliding with each
other — a Sluice site is gated against every Foundry row and the reverse.

| # | Dimension | What it records |
|---|---|---|
| 0 | **Phase** | `foundry` (value is an object) or `sluice` (value is duration). |
| 1 | **Grammar** | What the page *is*. Chaptered record, instrument panel, catalogue, ledger, dossier, single-object study, route, correspondence. |
| 2 | **Opening move** | What the first screen does before the visitor scrolls. |
| 3 | **Chapter device** | What a chapter unit is, and how it announces itself. |
| 4 | **Signature move** | The one bespoke interaction that exists on this site alone. |
| 5 | **Close pattern** | How the last screen behaves and how a commission is placed. |
| 6 | **Type + register** | Display-face class, and the light the site is set in. |

## The gate

**A new build must differ from every existing row on at least 4 of the 6.** Not
four on average across the table. Four against each row, individually.

Dimension 4 is free, because a signature move is unique by definition. So the
gate really asks for three more out of the remaining five, against each row. A
build that changes only place and palette will fail it, which is the point.

**If a planned build fails the gate, change the plan, not the table.** Rewriting
a row so a new build fits is the one thing that makes this file worthless. It
records what exists, not what we wish existed.

### What counts as a signature move

Bespoke, on this site alone, not a parameter change to something the collection
already does. Årringene's scribe counts. BENT's Sway counts. Veta's draw-your-board
counts.

**The test:** describe the move to somebody who has seen the other sites. If they
cannot tell it apart from something the collection already does, it is not a
signature move.

What does not count: the same readout with different labels, the same rail
scrolling the other way, a fourth alternating plate/text chapter, a hairline
meter with new terminal values.

## Known collisions

These were found by survey, not by review, and they are why this file exists.

**auriga / velum** — both aviation, both running `top → tails → board or
flight-path → legs/aloft → introduction`. One skeleton, two liveries.

**aresta / dar-el-warda** — both hospitality, both running `rooms → table →
stay → arrive → depart`.

**malmfuru / tyri** — both Norwegian log workshops. Both carry a `nov`/`novet`
chapter and a `tun`/`tunet` chapter. Deliberately different hours, identical
skeleton.

**malmfuru / bent** — the labelled hairline meter. `THE SCRIBE · 1791–2019` and
`STEEL RUNNING RAIL` are the same component: mono cap label, hairline rule,
accent fill, terminal values at the ends.

**The configurator cluster** — barchetta, nipis, rosee, traccia, tsutsumiya,
veta, faire and bent all run an SVG stage plus an `r-*` readout block plus a
`verdict` line plus a `live` price region. It is the collection's best pattern
and it is now eight sites deep. Treat it as spent unless the new subject demands
it *and* the drawing is genuinely different.

**The close** — nearly every site ends on a commission or order form. That is a
default nobody chose. Alternatives that have never been used here: a waiting
list with a real position, a season calendar with what is already taken, a
colophon that closes without asking for anything, a price list as a printed
sheet, a single letter with no fields at all.

### What the table says at a glance

- **Grammar:** three shapes across twenty-five sites — chaptered record,
  single-object study, hospitality record. Two dossiers. Nothing else has ever
  been tried.
- **Type:** one sans in the entire collection. Fraunces carries five sites.
- **Close:** a commission form on almost every row.
- **Signature move:** four are genuinely bespoke and named. Several rows cannot
  name one at all, which is itself the finding.

Rows marked `?` need a pass with eyes on the built page. Filling them is the
next job, and any row that still cannot name a signature move afterwards is a
site that never had one.
