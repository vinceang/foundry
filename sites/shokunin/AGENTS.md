# Shokunin — Bespoke Samurai Ateliers

Ultra-premium ecommerce showcase: a private commission house releasing twelve
works of samurai armor and blade a year. Dark lacquer world, smoked gold, kon
indigo. See `src/styles/global.css` for the full token system.

Identity rules (keep it separated from `sites/kaji`):

- **No red/vermilion anywhere** — red belongs to kaji.
- **No paper/washi background sections** — Shokunin stays nocturnal; light is gold.
- **No mono font** — labels are wide-tracked Manrope caps.
- Type: Marcellus (display) · Manrope (body/labels) · Zen Old Mincho (kanji only).

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

For the screenshot critique loop, `?nofx` on any URL disables entrance
animations and forces eager image loading.
