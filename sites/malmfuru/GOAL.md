# /goal

Add a Foundry site (Nocturne series) for a log cabin maker, somewhere Nordic.

Create a cinematic, ultra-premium site for **Malmfuru**, a family *laft*
(notched-log) workshop in Nore, Numedal, Norway — the medieval valley with
the densest stock of preserved log buildings in the country. The site should
feel like a rare private destination for people commissioning a house that
will outlive them.

This is part of the Foundry series as in the repo README. The register is
Nocturne: darkness as a material, one metal as light, scarcity as layout,
copy that proves instead of claims, one subject-specific signature
interaction.

Non-negotiables inherited from the series:

- A believable world before a visual style: place, family, numbers, and a
  vocabulary used consistently (laft, nov, medrag, malmfuru, setning,
  tinging, husbok, tunet).
- Materials are structural: the palette is winter night, hewn pine, copper
  light, and hearth — never generic tokens.
- Photography is evidence: one recipe, art-directed, generated; never
  lifestyle filler.
- One memorable interaction that could belong only to this subject.
- Fully self-contained under `sites/malmfuru` — own stack, tokens, DESIGN.md.
- Complete page with JS off; `?nofx` for the screenshot critique loop;
  images ≤500KB; no JS frameworks — static Astro + vanilla script.

This build is a dry run: no deploy, no git commits.
